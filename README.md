# Assignment 7: CSS Transitions and Animations

This project adds CSS micro-interactions to the supplied webpage.

## Interactions

- Header links animate a highlight underline and subtle glint on hover.
- The hero button lifts and pops on hover.
- Links in the main article reveal a sweeping underline on hover.
- Keyboard focus receives the same interaction cues, and motion is reduced when the visitor requests reduced motion.
